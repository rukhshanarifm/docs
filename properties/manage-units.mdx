Units represent the individual dwellings or spaces within a property — such as flats, apartments, or commercial units. Each unit can have a customer and one or more meters assigned to it, making units the central link between a physical space and the billing and metering data associated with it.

<Tip>
  Use a consistent naming convention for your units — for example, Flat 1 or Unit 1A — so they are easy to identify and search for later.
</Tip>

## Adding a unit to a property

<Steps>
  <Step title="Navigate to the property">
    Open the Properties section and select the property you want to add a unit to.
  </Step>
  <Step title="Add a new unit">
    Select the option to add a unit within that property.
  </Step>
  <Step title="Enter the unit details">
    Provide a unit identifier or name. This is the label that will appear throughout Network Manager to identify the unit.
  </Step>
  <Step title="Save the unit">
    Save the unit. It will now appear in the unit list for that property.
  </Step>
</Steps>

## Editing unit details

To update a unit's name or identifier, navigate to the property, locate the unit in the list, and select the option to edit it. Update the details as needed and save your changes.

## Viewing all units in a property

To see all units belonging to a property, navigate to the Properties section and select the relevant property. The property view lists all units associated with it, along with any assigned customers and meters.
