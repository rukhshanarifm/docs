---
title: "How to Create a Property Record in Network Manager"
sidebarTitle: "Add a Property"
description: "Add a property when you bring a new building or site onto your network. Each property acts as a container for the units and meters within it."
---

When you bring a new building or site onto your network, you start by creating a property record. The property acts as the top-level container for all the units, meters, and customers associated with that site.

<Steps>
  <Step title="Navigate to the Properties section">
    Open the Properties section from the main navigation.
  </Step>
  <Step title="Add a new property">
    Select the option to add a new property.
  </Step>
  <Step title="Enter the property details">
    Provide the property name and address. These details identify the property throughout Network Manager.
  </Step>
  <Step title="Save the property record">
    Save the property. It will now appear in your properties list and be ready for units to be added.
  </Step>
</Steps>

<Note>
  After creating the property, add units to represent the individual dwellings or spaces within it. See [Manage Units](/properties/manage-units) to get started.
</Note>
